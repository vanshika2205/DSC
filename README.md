# 🐉 3D CSS Image Slider

An interactive and visually stunning **3D Image Slider** built using pure HTML and CSS. The project showcases advanced CSS techniques including perspective transforms, smooth animations, and carousel effects to create an immersive browsing experience.

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/vanshika2205/3D-CSS-Image-Slider.git
```

Navigate to the project folder:

```bash
cd 3D-CSS-Image-Slider
```

Open `index.html` in your browser.
